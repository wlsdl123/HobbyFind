# 3.4 고정 취미 목록 (Fixed Hobby Catalog)

## 목적

서비스에서 제공하는 취미 목록은 프로젝트 실습의 범위를 명확하게 하기 위해 **고정된 데이터셋(Fixed Dataset)** 을 사용한다.

* 취미 목록은 **변경하거나 추가할 수 없다.**
* 모든 페이지는 아래 목록만 사용하여 화면을 구성한다.
* 검색, 추천, 관리자 기능 등을 통해 목록이 변경되지 않는다.
